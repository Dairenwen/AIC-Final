华为云 Docker 部署准备（尚未完成云端验收；RDS 与 DCS 的连接尚未在真实实例上验证）

本包包含历史用户数据。请在当前用户专属、权限为 0700 的新目录中解压，
不要把部署包或数据放入公开目录；不要覆盖已有项目或数据。

1. 生产环境使用 Linux x86_64、Docker、Docker Compose、python3、openssl 和 curl。
   Elasticsearch 8.19 要求宿主机 vm.max_map_count 至少为 1048576；请由服务器
   管理员事先配置。预留论文、数据包解压、约 1.3 GiB 发布快照和镜像构建空间。
2. 复制 production.env.example 为同目录 .env.production，将文件权限设为 0600，
   填写生产域名、应用密钥，以及下面第 2a、2b 条的云数据库和缓存地址；旧密文能否
   解密取决于原加密密钥。私有配置不要打包发布或放入开源仓库。
   PUBLIC_ORIGIN 目前在模板里留空：没有已备案域名和证书时预检会明确拒绝，
   不会以不安全的方式启动。
2a. 数据库使用华为云 RDS for PostgreSQL，生产环境不再在云主机上运行数据库容器。
   - 版本必须是 18（交接备份由 PostgreSQL 18 导出，低版本会被启动脚本拒绝）。
   - 与云主机放在同一 VPC，安全组只对云主机放行 5432，不开公网。
   - 数据库须用 C 排序规则创建，否则历史数据的排序与原库不一致：
       CREATE DATABASE zhiyan TEMPLATE template0 ENCODING 'UTF8'
         LC_COLLATE 'C' LC_CTYPE 'C';
     并创建一个对该库有建表权限的专用账号，密码只用字母、数字、下划线和连字符。
   - 把内网地址填入 POSTGRES_HOST，端口、库名、账号、密码填入对应项。
   - 首次启动时后端容器会把交接备份以单个事务恢复进这个空库；库里已有业务表时
     不会覆盖。恢复只需要普通建表权限，不需要超级用户。
2b. 缓存使用华为云 DCS Redis（单机或主备均可，Redis 6 及以上），同一 VPC、
   安全组只对云主机放行 6379。连接地址填入 REDIS_URL，
   例如 redis://:密码@内网地址:6379/0 。后端用它保存短信验证码的发送间隔和
   智能体就绪状态的缓存；Redis 暂时不可用时这两项退回进程内存，服务不中断，
   /api/v1/health/ready 的 components.redis 会显示 unavailable。
2c. 需要 Docker Compose 2.24.6 或更高版本（生产编排用到了 !override）。
3. 将域名的证书链和私钥分别放在本目录 tls/fullchain.pem、tls/privkey.pem，
   服务器需开放 HTTPS 443，并确认域名解析及证书有效；证书链须受服务器的
   系统证书库信任，包含必要的中间证书且可用于 HTTPS 服务端。
4. 完整私有部署包包含数据库备份、现有历史附件、论文和 Docling 模型；解压后
   确认补充/docling_hf/hub/ 存在。没有备份或模型时预检拒绝启动。
5. Elasticsearch 在同一台服务器的独立容器中运行，需设置独立的内部访问密码；
   硅基流动向量和重排接口需分别填写 API Key。模板使用旧 Milvus 集合
   paper_chunks_bge_m3。关键词索引从已有数据库重建，云端完整检索仍需验收。
   已获授权：仅对本次可验证的新恢复库，首次启动补齐空路径且文件名与论文 ID
   完全匹配的 PDF 记录；不覆盖已有路径，完成后不重复执行。旧论文只读，新上传
   保存在持久化数据卷。备份含 8530 篇活动论文，但现有 68 个向量仅对应 36 篇；
   后续为可解析论文分批建全文索引前，须另行核实资源费用和接口限制并确认。
6. 预检：bash deploy/huawei/deploy.sh --check
   资源、依赖、代码与数据完整验收并经授权后：bash deploy/huawei/deploy.sh --apply
   apply 不会购买云资源。首次执行生成独立只读代码快照并恢复数据；相同配置下
   失败可重试、成功后可重启。检测到未登记的容器/数据卷或快照损坏会停止；
   已发布版本的升级及数据库回滚仍需备份并另行处理。
7. 27B 模型本次保持关闭；未来启用时需另行核对接口与费用。
8. Mermaid 使用独立无网络容器，通过 Unix socket 通信；容器非 root、只读、
   禁止提权、丢弃所有 capabilities，资源上限 2 CPU / 2 GiB。经负责人同意，
   仅在这个容器中关闭 Chromium 内部沙箱。本机已验证绘图调用，目标机仍需验收。
9. 通过管理接口全量重建索引时，知识库写入会暂时停止；向量重建须显式确认
   可能产生的 API 费用。单机维护锁不保护手动直连数据库或其他主机的写入。
10. 云端部署、完整真实业务、生产证书和升级回滚尚未全部实测；不能将本文件或
    健康检查作为全部功能成功的证明。CodeArts 应实际使用华为已有部署 Skill，
    保存真实脱敏记录；项目内 Skill 只是适配指引，不代替官方 Skill 的调用。
